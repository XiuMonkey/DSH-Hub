三条规则的落实

  • 规则 1空行只在逻辑块之间。 include 区连成一片（收掉 33% 的 include 区空行）；块内不再撒空行， 同类连续语句连排；任何地方最多连续 1 个空行。
  • 规则 2注释只留约束与坑。 删掉论证过程、历史沿革、举例与括号补充、复述代码的注释、ASCII 分节横幅、空注释行。 每个注释块 ≤ 2 行，文件头 ≤ 4 行；行尾 // 一律 ≤ 25 字。 注释行 3619 → 2040（-44%）。
  • 规则 3函数实参不拆行。 能塞进 120 列的实参合并回同一行，用 , 分隔；续行只加 1 个 Tab， 不再对齐到括号下方；lambda 等"体内多行"的实参仍各占自己那一段。

怎么回退 / 怎么继续

  • 整体回退：git revert b8edba2e，或 git checkout cf9ba8ab -- source/ 只还原源码。
  • 看单个文件：git diff cf9ba8ab..b8edba2e -- source/src/core/DSHHub.cpp
  • 防止再被弄脏：根目录已放 .clang-format（Tab 缩进、列宽 120、 实参不拆行、大括号 Allman）。改完代码跑一次 clang-format -i <文件> 即可对齐。按你的选择，现有代码没有被它批量重排。
  • 被删掉的信息：注释里的设计论证/历史沿革被删了，原文都在 cf9ba8ab 这个快照里，需要时用 git 翻。
